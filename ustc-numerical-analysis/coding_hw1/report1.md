**1. 实验目的**

1.  掌握 Lagrange 插值和 Hermite 插值的原理和编程实现。
2.  理解等距插值节点和切比雪夫插值节点的区别及其对插值效果的影响。
3.  观察和分析高次多项式插值的龙格 (Runge) 现象。
4.  掌握分片线性插值和分片三次 Hermite 插值的原理和实现。
5.  比较不同插值方法（全局多项式 vs 分片）和不同节点选择下的插值误差，分析误差随节点数 $n$ 变化的趋势。

**2. 实验原理与方法**

**2.1 插值函数**

- $f_1(x) = \sqrt{1 - x^2}, \quad x \in [-1, 1]$ (半圆函数)
- $f_2(x) = \frac{1}{1+25x^2}, \quad x \in [-1, 1]$ (龙格函数)

**2.2 插值节点**

- **等距节点 (Equispaced Nodes):** $x_k = -1 + \frac{2k}{n}, \quad k = 0, 1, \dots, n.$
- **切比雪夫节点 (Chebyshev Nodes):** $x_k = \cos\left(\frac{2k+1}{2(n+1)}\pi\right), \quad k = 0, 1, \dots, n.$

**2.3 插值方法**

- **Lagrange 插值:** 对于给定的 $n+1$ 个节点 $(x_k, y_k)$，构造唯一的 $n$ 次多项式 $P_n(x)$ 使得 $P_n(x_k) = y_k = f(x_k)$。其形式为 $P_n(x) = \sum_{k=0}^{n} y_k L_k(x)$，其中 $L_k(x) = \prod_{j=0, j\neq k}^{n} \frac{x-x_j}{x_k-x_j}$ 是 Lagrange 基函数。实验中使用了 `numpy.poly1d` 和自定义的 `lagrange` 函数实现。
- **Hermite 插值:** 对于给定的 $n+1$ 个节点 $(x_k, y_k, y'_k)$，构造唯一的 $2n+1$ 次多项式 $H_{2n+1}(x)$ 使得 $H_{2n+1}(x_k) = y_k = f(x_k)$ 且 $H'_{2n+1}(x_k) = y'_k = f'(x_k)$。实验中通过构造带重节点的差商表来实现。所需导数 $f'_2(x) = \frac{-50x}{(1+25x^2)^2}$。
- **分片线性插值:** 在每个子区间 $[x_k, x_{k+1}]$ 上使用连接 $(x_k, y_k)$ 和 $(x_{k+1}, y_{k+1})$ 的线性函数进行插值。使用 `numpy.interp` 实现。
- **分片三次 Hermite 插值:** 在每个子区间 $[x_k, x_{k+1}]$ 上使用满足端点函数值和导数值的三次多项式进行插值，保证拼接后的函数一阶导数连续。通过 Hermite 基函数 $h_{00}(t), h_{10}(t), h_{01}(t), h_{11}(t)$ 实现，其中 $t = (x-x_k)/h$，$h=x_{k+1}-x_k$。

**2.4 误差度量**
采用均匀选取的 $N+1$ 个测试点 $\tilde{x}_j = -1 + \frac{2j}{N}$ ($N=200$) 上的最大绝对误差来近似区间 $[-1, 1]$ 上的最大误差：
$$ E*n = \max*{x \in [-1, 1]} |f(x) - P(x)| \approx \max\_{0 \le j \le N} |f(\tilde{x}\_j) - P(\tilde{x}\_j)| $$
误差结果使用科学计数法表示，保留三位有效数字。

**4. 实验结果与分析**

**4.1 Lagrange 插值 (等距节点)**

- **误差表格:**
  ```
  | n | f1 error | f2 error |
  |---|----------|----------|
  | 5 | 1.525e-01 | 4.327e-01 |
  | 10 | 8.822e-02 | 1.916e+00 |
  | 20 | 5.587e-02 | 5.859e+01 |
  | 40 | 4.305e+06 | 3.018e+06 |
  ```
- **n=20 插值图像:** (根据 Notebook 输出描述)

  - 对于 $f_1(x) = \sqrt{1-x^2}$，插值多项式在区间中部拟合较好，但在靠近端点 $-1$ 和 $1$ 处出现较大的偏差和振荡。
  - 对于 $f_2(x) = \frac{1}{1+25x^2}$，插值多项式在区间中部拟合尚可，但在靠近端点处出现剧烈的振荡，峰值远超原函数的最大值 1，这是典型的龙格现象。

- **分析:**
  - 对于 $f_1(x)$，误差先减小后增大，表明高次插值可能不稳定，特别是在端点附近（导数趋于无穷）。$n=40$ 时误差异常巨大，这很可能是由于高次多项式插值带来的数值不稳定性和浮点误差累积导致的。
  - 对于龙格函数 $f_2(x)$，随着插值次数 $n$ 的增加，最大误差急剧增大。这清晰地展示了使用等距节点进行高次多项式插值的龙格现象：插值多项式在区间两端附近会产生剧烈的振荡，导致误差发散。$n=40$ 时误差同样巨大，也伴有数值不稳定问题。

- **n=20 插值图像:** (根据 Notebook 输出描述)

  - 对于 $f_1(x)$，插值多项式的拟合效果比等距节点有改善，尤其是在端点附近振荡减弱。
  - 对于 $f_2(x)$，插值多项式的拟合效果显著优于等距节点，端点处的振荡被有效抑制，最大误差明显减小。

- **分析:**
  - 使用切比雪夫节点，对于两个函数，在 $n=5, 10, 20$ 时，误差都呈现下降趋势。切比雪夫节点在区间端点处分布更密集，能够有效抑制龙格现象，提高插值的收敛性和稳定性。
  - 对于 $n=40$，两个函数的误差仍然异常巨大。这表明即使使用切比雪夫节点，当插值次数非常高时，Lagrange 插值的计算（尤其是基于差商或基函数求和的方式）可能仍然会遇到严重的数值不稳定问题，导致计算结果不可靠。这更可能是计算方法本身在高次时的局限性或特定实现的数值问题，而不是插值理论本身的误差。

- **分析:**

  - 分片三次 Hermite 插值的误差收敛速度大约是 $O(h^4)$。当 $n \to 2n$ 时，$h \to h/2$，误差变为原来的 $(1/2)^4=1/16$，这与观测到的误差比约为 16 基本一致。分片 Hermite 插值具有更高的收敛阶，因此在相同节点数下通常能达到更高的精度。

**5. 结论**

1.  使用等距节点进行高次 Lagrange 或 Hermite 多项式插值时，对于某些函数（如龙格函数 $f_2(x)$），容易出现龙格现象，即在区间端点附近产生剧烈振荡，导致误差随插值次数 $n$ 的增加而增大，不收敛。
2.  使用切比雪夫节点进行高次 Lagrange 插值，可以显著改善插值的收敛性和稳定性，有效抑制龙格现象。
3.  对于非常高的插值次数 ($n=40$ 在本实验中)，即使使用切比雪夫节点，基于 Lagrange 公式（或差商）的直接计算也可能因数值不稳定而产生巨大误差。
4.  分片插值方法（线性和 Hermite）对于龙格函数表现出良好的收敛性，误差随节点数 $n$ 的增加而稳定减小。
5.  分片三次 Hermite 插值的收敛速度（约为 $O(h^4)$）显著快于分片线性插值（约为 $O(h^2)$）。
6.  在实际应用中，对于需要高精度插值的场景，应优先考虑使用切比雪夫节点的多项式插值（对光滑函数）或分片高次插值（如分片 Hermite 或样条插值），避免使用等距节点的高次全局多项式插值。
