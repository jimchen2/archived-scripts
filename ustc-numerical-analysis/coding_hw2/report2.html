1. 实验目的

本实验旨在通过编程实践，加深对数值积分方法的理解，包括：

  • 实现并应用复化梯形积分和复化 Simpson 积分。
  • 数值验证不同积分方法的收敛阶。
  • 探究被积函数震荡性对收敛速度和所需计算量的影响。
  • 实现 Romberg 积分并观察其加速收敛的效果。
  • 实现二维复化 Simpson 积分并应用于具体算例。

2. 问题描述

主要研究对象是如下积分函数：

f(x)=∫∗01g(t,x) dt=∫∗01[t+sin⁡(xt2)] dtf(x) = \int*{0}^{1} g(t, x) \, \mathrm{d}t = \int*{0}^{1} [t + \sin(x t^2)] \, \mathrm{d}t f(x)=∫∗01g(t,x)dt=∫∗01[t+sin(xt2)]dt

此外，还需计算两个二重积分。

  • 编程语言: Python 3
  • 主要库: NumPy, math

4.3 收敛阶在 n 很小或很大时的行为

  • 当 n 很小时: 理论误差公式 En≈ChpE_n \approx C h^pEn​≈Chp 是基于 h→0h \to 0h→0 的渐进行为，忽略了 hhh 的高阶项。当 nnn 很小，步长 h=(b−a)/nh = (b-a)/nh=(b−a)/n 较大时，这些被忽略的高阶项（如 O(h3),O(h4)O(h^3), O(h^4)O(h3),O(h4) 对梯形， O(h5),O(h6)O(h^5), O(h^6)O(h5),O(h6) 对 Simpson）相对显著，导致实际误差行为偏离 ChpCh^pChp，因此观察不到清晰的理论收敛阶。这可以理解为 "分辨率不足"，即用很少的节点无法捕捉函数的细节。

  • 当 n 很大时: 理论上，截断误差会持续按 hph^php 下降。但在实际计算机运算中，使用的是有限精度的浮点数（如 float64）。当 nnn 非常大时，hhh 变得极小：

    1. 舍入误差累积: 大量数值加法会导致舍入误差的累积。
    2. 舍入误差主导: 当 nnn 足够大，截断误差 ChpCh^pChp 可能变得比累积的舍入误差还要小。此时，总误差不再由截断误差主导，而是由舍入误差决定（或者达到机器精度极限）。舍入误差通常不会随着 nnn 的增加而按 hph^php 规律性减小（甚至可能略微增加或波动），因此观察不到理论收敛阶。
