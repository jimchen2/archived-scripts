**1. 实验目的**

本实验旨在通过编程实践，加深对数值积分方法的理解，包括：

- 实现并应用复化梯形积分和复化 Simpson 积分。
- 数值验证不同积分方法的收敛阶。
- 探究被积函数震荡性对收敛速度和所需计算量的影响。
- 实现 Romberg 积分并观察其加速收敛的效果。
- 实现二维复化 Simpson 积分并应用于具体算例。

**2. 问题描述**

主要研究对象是如下积分函数：
$$ f(x) = \int*{0}^{1} g(t, x) \, \mathrm{d}t = \int*{0}^{1} [t + \sin(x t^2)] \, \mathrm{d}t $$
此外，还需计算两个二重积分。

**3. 实验环境**

- **编程语言:** Python 3
- **主要库:** NumPy, math

**4. 实验内容与结果分析**

**4.3 收敛阶在 n 很小或很大时的行为**

- **当 n 很小时:** 理论误差公式 $E_n \approx C h^p$ 是基于 $h \to 0$ 的渐进行为，忽略了 $h$ 的高阶项。当 $n$ 很小，步长 $h = (b-a)/n$ 较大时，这些被忽略的高阶项（如 $O(h^3), O(h^4)$ 对梯形， $O(h^5), O(h^6)$ 对 Simpson）相对显著，导致实际误差行为偏离 $Ch^p$，因此观察不到清晰的理论收敛阶。这可以理解为 "分辨率不足"，即用很少的节点无法捕捉函数的细节。

- **当 n 很大时:** 理论上，截断误差会持续按 $h^p$ 下降。但在实际计算机运算中，使用的是有限精度的浮点数（如 `float64`）。当 $n$ 非常大时，$h$ 变得极小：
  1.  **舍入误差累积:** 大量数值加法会导致舍入误差的累积。
  2.  **舍入误差主导:** 当 $n$ 足够大，截断误差 $Ch^p$ 可能变得比累积的舍入误差还要小。此时，总误差不再由截断误差主导，而是由舍入误差决定（或者达到机器精度极限）。舍入误差通常不会随着 $n$ 的增加而按 $h^p$ 规律性减小（甚至可能略微增加或波动），因此观察不到理论收敛阶。

**4.5 Romberg 积分 (x=1, 100, ε=1e-12)**

使用 Romberg 积分方法计算 $f(1)$ 和 $f(100)$，精度要求 $\epsilon = 10^{-12}$。

- **x = 1:**
  - 积分值: 8.102683017234e-01
  - 迭代次数 (k, 使得 $n=2^k$): 6 (即计算到 $R(6,6)$)
- **x = 100:**
  - 积分值: 5.583670899930e-01
  - 迭代次数 (k): 12 (即计算到 $R(12,12)$)

**分析:** Romberg 积分通过对梯形公式结果进行外推加速，能够用较少的函数求值次数达到高精度。对于震荡更剧烈的 $x=100$，需要更多的迭代次数（更高阶的外推和更精细的初始梯形计算）才能达到相同的精度要求。

**4.6 二重积分的复化 Simpson 积分**

实现了二维复化 Simpson 积分函数 `composite_simpson_double(f, a, b, c, d, nx, ny)`。
